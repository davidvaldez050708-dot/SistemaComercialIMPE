La vista app/views/convocatorias/index.php deja de renderizar el botón «Nueva convocatoria» y el modal modalCrearConvocatoria en el listado normal de Gestión de Convocatorias. No se trata de ocultarlo con CSS: el formulario no forma parte del HTML de esa pantalla. El cambio de producción consiste en una condición para el botón y una condición alrededor del modal, en la misma vista.

Se conserva íntegro el contexto legado desde_convenio y no se modifica el módulo independiente Crear convocatoria (crear_desde_convenio.php y CrearConvocatoriaController). No hay cambios en endpoints de guardado, modelos, permisos, validaciones, filtros, edición, activación, detalle, imagen, QR, contadores, JavaScript o CSS. La apertura automática existente ya comprueba si el modal existe; en Gestión no abre nada y en el contexto de Convenios funciona igual.
