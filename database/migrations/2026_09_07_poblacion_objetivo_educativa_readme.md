# Población objetivo educativa

Este cambio agrega una fuente oficial separada del rezago educativo de Pobreza Multidimensional.

Indicador inicial: población de 15 años y más con secundaria completa, publicado por INEGI/SCITEL.

La estructura queda preparada para agregar posteriormente un indicador más estricto de continuidad educativa (por ejemplo, secundaria completa + condición de no asistencia escolar) sin cambiar el significado del rezago educativo ya existente.
