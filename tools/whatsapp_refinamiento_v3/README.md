# Refinamiento WhatsApp V3 (candidato CHECK)

Sólo WhatsApp y el pequeño gancho de toast de WhatsApp. Nombres del expediente primero, toast institucional con nombre separado, historial calculado sobre mensajes reales (no sobre resumen persistido mezclado), dirección Tú:, refresco de lista de conversaciones cada 10 s visible sin marcar lectura por la consulta de lista, reutiliza fragmento PHP del índice y búsqueda. No cambia la zona global ni históricos. Para salida usa created_at UTC (instante de registro, no pretende inferir hora exacta del proveedor), entrada usa enviado_at local; diagnóstico agregado verifica evidencia de ese contrato en Hostinger. Salidas nuevas usan fecha local explícita y created_at UTC; la ventana de 24 h existente conserva formato México. No se hace una migración UTC masiva. El resumen histórico persistido puede conservar su valor anterior, pero la lista se reconstruye en lectura. CHECK y prueba unitaria no son aprobación de publicación. Faltan pruebas SQL de integración y navegador con bases exactas, además de validar permisos/lecturas y preparar publicador reversible. No desplegar rama completa.
